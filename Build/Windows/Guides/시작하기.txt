Missing Floor Windows {EDITION_KO} {VERSION} ({DATE_DOT})

ZIP 파일의 압축을 모두 푼 뒤 MissingFloor.exe를 실행해 주세요.
Engine, IndieGame 폴더도 실행 파일 옆에 있어야 합니다.
Unreal Engine이나 Visual Studio는 설치하지 않아도 됩니다.
화면이 끊기면 설정에서 그래픽 품질을 낮음으로 바꾸거나 해상도를 낮춰 보세요.

WASD: 이동 / 마우스: 둘러보기 / 왼쪽 Shift: 달리기 / C: 앉기 / Space: 점프
E: 조사 · 상호작용 / E 길게 누르기: 문 조용히 열기, 벽에 귀 대기
Q: 두드리기 / 왼쪽 Ctrl: 숨 참기 / F: 손전등
Tab: 기록 보기(낮) / H: 힌트 / ← →, 마우스 휠: 문서 넘기기
F1: 목표 · 조작 안내 / F10: 난이도와 접근성 설정 / Esc: 일시정지
게임패드도 지원합니다. 조작키는 설정에서 바꿀 수 있습니다.

진행 상황은 자동으로 저장됩니다. 다음에 실행할 때는 ‘이어하기’를 선택해 주세요.
처음 실행할 때 소리와 밝기를 맞춰 주세요.
쫓기는 게 부담스러우면 F10에서 난이도를 추격 없음으로 바꿀 수 있습니다.
처음에는 Windows 표시 언어에 맞춰 실행됩니다. 설정 > 일반 > 언어 · Language에서 바꿀 수 있습니다.
