# Missing Floor

ソウルの古い集合住宅を舞台にした一人称ホラーゲームです。Unreal Engine 5で制作中で、Windows向けの無料体験版を配布しています。

![雨上がりの路地の奥に建つ4階建ての集合住宅。窓の明かりは二つだけ](../Media/readme/title-menu-first-run-1080-ja.webp)

返送されてきた荷物に書かれていた兄の住所は、月光ヴィラの501号室。
けれど、この建物は4階までしかない。

兄を捜して403号室に越してきたその夜、午前4時半。
上の階などない天井を、誰かが三回叩く。

[体験版をダウンロード（Windows・0.2.4）](https://github.com/easygap/Missing-Floor/releases/download/v0.2.4/MissingFloor-0.2.4-Windows.zip) · [トレーラー](https://github.com/easygap/Missing-Floor/releases/download/v0.2.3/MissingFloor-Trailer.mp4) · [操作方法](#操作方法)

## 昼

手がかりは返送された荷物と、留守番電話のメッセージが一件だけ。401号室のおばあさんはこの建物に30年住んでいて、路地の向かいのコンビニで働くアルバイトの子は近所のうわさをよく知っています。兄を覚えている人がいるかもしれません。

管理人室の帳簿と防犯カメラの記録は、どこかが食い違っています。電気メーターを数えたり、壁に耳を当てたりしてみてください。読んだ記録は`Tab`で読み返せます。行き詰まったら`H`でヒントが出ます。

舞台がソウルなので、看板や貼り紙は韓国語のままです。話に関わる書類は、調べると日本語で表示されます。

## 夜

毎朝4時半から5時半まで、この建物には目を覚ましているものがいます。

上の階の人は目が見えず、音をたよりに近づいてきます。走らないで、ドアはゆっくり開けてください。すぐ近くまで来たら息を止めましょう。

暗い場所に長くいると、闇が寄り集まってきます。見つめるほど大きくなるので、目をそらして明かりのあるところへ行ってください。

ドアの外から知っている人の声がしても、開けてはいけません。

![懐中電灯に照らされた夜の管理人室の机](../Media/readme/game-booth.webp)

洋服ダンスやベッドの下に隠れたり、玄関の掛け金をかけたり、階段室の防火扉を閉めておいたりもできます。懐中電灯の電池は減っていくので、コンビニで買っておきましょう。

捕まってもゲームオーバーにはなりません。自分の部屋で目を覚まし、見つけた手がかりもそのままです。ただ、時間は戻りません。

## ダウンロード

いま配布しているのは体験版0.2.4です。隠れる場所、掛け金と防火扉、懐中電灯の電池、それから上の階の人以外に夜やってくるものは、次の体験版で追加されます。

1. [Windows用のZIP](https://github.com/easygap/Missing-Floor/releases/download/v0.2.4/MissingFloor-0.2.4-Windows.zip)をダウンロードします。
2. ZIPをすべて展開して`MissingFloor.exe`を起動します。同じフォルダーの`Engine`と`IndieGame`がないと起動しません。
3. 「ゲームを始める」を選びます。進行は自動で保存され、次回からは「つづきから」で再開できます。

「WindowsによってPCが保護されました」と表示されたら、「詳細情報」を押してから「実行」を選んでください。実行ファイルに署名がないために出る画面です。

ゲームは日本語、韓国語、英語、中国語（簡体字・繁体字）に対応しています。初回はWindowsの表示言語で起動し、設定から切り替えられます。[起動ガイド](../PLAYING.md)は今のところ韓国語版しかありません。動作を確認したPCと、起動しないときの対処が書いてあります。

## 操作方法

| キー | 操作 |
|---|---|
| WASD・マウス | 移動・視点移動 |
| 左Shift・C・Space | ダッシュ・しゃがむ・ジャンプ |
| E | 調べる・ドアを開ける・隠れる |
| E長押し | ドアを静かに開け閉めする・壁に耳を当てる |
| Q | ノック |
| 左Ctrl | 息を止める |
| F | 懐中電灯 |
| F1 | 目標と操作 |
| Tab・H | 調査記録（昼）・ヒント |
| ← →・マウスホイール | ページをめくる |
| Esc・F10 | 一時停止・アクセシビリティ設定 |

ゲームパッドでも遊べます。キーとボタンの割り当ては設定で変更できます。

## 難易度とアクセシビリティ

追いかけられるのがつらいときは、`F10`で難易度を「追跡なし」にしてください。何にも捕まらずに、物語と謎解きを最後まで遊べます。どの難易度でも、すべてのエンディングにたどり着けます。

字幕の大きさと背景、音の方向表示、画面の揺れ、光の点滅、画面の質感を調整できます。長押しがつらければ、一回押すだけで始まる方式に切り替えられます。マイク入力は任意で、初期設定ではオフです。

## 使用素材

効果音はOpenGameArtとKenneyのCC0素材を加工して使わせていただきました。写真テクスチャはambientCG、スキャンした小物はPoly Havenのもので、どれもCC0です。フォントはPretendardとGowun Batangで、どちらもSIL Open Font License 1.1です。印刷物や参考画像の一部は、画像生成モデルで作ったものに手を加えています。素材ごとの出典とライセンスは[素材台帳](../ASSET_POLICY.md)（韓国語）にまとめてあります。

## 不具合・感想

ゲームが止まったり、おかしな動きをしたりしたら、[不具合報告](https://github.com/easygap/Missing-Floor/issues/new?template=bug_report.yml)に場面と症状を書いてください。[感想や提案](https://github.com/easygap/Missing-Floor/issues/new?template=feedback.yml)も受け付けています。まだ作りかけで、粗いところがたくさんあります。

ソースからビルドする手順は、[起動ガイドの「소스에서 빌드하기」](../PLAYING.md#소스에서-빌드하기)（韓国語）にあります。Unreal Engine 5.8、Visual Studioの「C++によるゲーム開発」ワークロード、Windows SDK、Git LFSが必要です。
