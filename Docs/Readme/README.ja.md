# Missing Floor

兄が最後に残した住所は、月光ヴィラ501号室。その建物は4階までしかない。

ソウルの古い集合住宅を舞台にした一人称ホラーゲームです。行方不明の兄を捜して403号室に越してきたユダムとして、昼は住人の話や記録を調べ、夜明け前は天井の上から降りてくるものを避けて過ごします。Unreal Engine 5で開発中で、Windows向けのテスト版を無料で公開しています。

![雨上がりの路地の奥に建つ4階建ての集合住宅。窓の明かりは二つだけ](../Media/readme/title-menu-first-run-1080-ja.webp)

いま遊べるのはテスト版0.9.1（Windows）です。日本語、韓国語、英語、中国語（簡体字・繁体字）に対応しています。

[テスト版をダウンロード（Windows・0.9.1）](https://github.com/easygap/Missing-Floor/releases/download/v0.9.1/MissingFloor-0.9.1-Windows.zip) · [トレーラー（英語字幕）](https://github.com/easygap/Missing-Floor/releases/download/v0.9.0/MissingFloor-Trailer-en.mp4) · [操作方法](#操作方法)

## 昼

引っ越した最初の夜、午前4時半に天井から三回叩く音がします。403号室は最上階です。

明るくなったら、兄の足取りを追って建物と路地を歩き回ります。401号室のおばあさんはこの建物に30年住んでいて、路地の向かいのコンビニで働くナリンは近所の事情にくわしい人です。

1階の管理人室のドアには粗大ごみ回収のお知らせが貼ってあります。回収日は線で消して早められていて、202号室のジョンウは管理人室に積んであった「持ち主のいない荷物」を302号室へ運んでいるところです。その箱のなかに、兄の字が書かれた箱がひとつあります。

## 午前4時半

午前4時半から5時半まで建物は閉ざされ、「上の階の人」が廊下を這い回ります。目は見えず、音を聞いています。走ったりドアを強く閉めたりすればそちらへ来るし、すぐそばを通るときは息を止めるしかありません。

明かりのない場所に長くいると黒い人影が現れ、見つめるほど大きくなります。玄関の外から聞き覚えのある声がしても、ドアを開けてはいけません。

管理人室の奥の部屋と302号室、5階の壁には、防音材が何重にも貼りつけてあります。そこに貼りついているものは音にも光にも反応せず、壁の中へ通じるすき間を探して、広いほうから体でふさぎます。点検口を開けてそれを別のすき間へ移したり、倒れた板をくさびで支えて通り道を作ったりする場面があります。通り道に立っていると、板とその体のあいだに挟まれます。

![5階の壁の前。防音材と鉄骨でできたものが、天井まで体を広げている](../Media/readme/game-annex-lining.webp)

![明かりの消えた廊下。ドアの下から隣の部屋の明かりが漏れている](../Media/readme/game-corridor-night-ja.webp)

クローゼットやベッドの下に隠れたり、玄関の掛け金と階段の防火扉で行く手をふさいだりできます。懐中電灯の電池は昼のうちにコンビニで買えます。

捕まっても、その夜を最初からやり直すことはありません。気がつくと引きずられていった場所にいて、そのあいだに何分か過ぎています。何に捕まったかで失うものが違います。「上の階の人」に捕まると、懐中電灯は捕まった場所の床に落ちていて、そこまで拾いに戻ることになります。

その夜に確かめることを確かめたら、403号室のベッドで横になって朝を迎えられます。5時半まで見て回ってもかまいませんが、やることが終わっていなければ、次の晩にその夜をもう一度過ごします。

## ダウンロード

いま配布しているのはテスト版0.9.1です。正式な1.0の前に、いろいろなPCと初めて遊ぶ方に確かめてもらうための候補版です。

1. [Windows用のZIP](https://github.com/easygap/Missing-Floor/releases/download/v0.9.1/MissingFloor-0.9.1-Windows.zip)をダウンロードします。
2. すべて展開して`MissingFloor.exe`を起動します。同じフォルダーにある`Engine`と`IndieGame`フォルダーがないと起動しません。
3. 「ゲームを始める」を選びます。進行は自動で保存され、次からは「つづきから」で再開できます。

実行ファイルに署名がないため、初回に「WindowsによってPCが保護されました」と出ることがあります。「詳細情報」から「実行」を選べば起動します。

言語は最初はWindowsの表示言語に合わせ、設定で変えられます。動作を確認したPCと、起動しないときに試すことは[起動ガイド](../PLAYING.md)（韓国語）にまとめています。

## 操作方法

| キー | 操作 |
|---|---|
| WASD・マウス | 移動・視点移動 |
| 左Shift・C・Space | ダッシュ・しゃがむ・ジャンプ |
| E | 調べる・ドアを開ける・隠れる |
| E長押し | ドアを静かに開け閉めする・壁に耳を当てる |
| Q | ノック |
| 左Ctrl | 息を止める |
| F | 懐中電灯 |
| F1 | 目標と操作 |
| Tab・H | 調査記録（昼）・ヒント |
| ← →・マウスホイール | ページをめくる |
| Esc・F10 | 一時停止・アクセシビリティ設定 |

ゲームパッドでも遊べます。キーとボタンの割り当ては設定で変えられます。

## 難易度とアクセシビリティ

追われるのがつらければ、`F10`で難易度を「追跡なし」にできます。捕まることがなくなり、物語と謎解きだけを追えます。どの難易度でも見られるエンディングは同じです。

字幕の大きさと背景、音の方向表示、画面の揺れ、光の点滅、レンズの歪みを調整できます。押し続ける操作は、一度押すと続くように切り替えられます。マイク入力は初期設定ではオフです。

![アクセシビリティ設定の画面](../Media/readme/settings-accessibility-20260929-ja.webp)

## 使用素材

効果音はOpenGameArtとKenney、床と壁のテクスチャはambientCG、実物をスキャンした小物はPoly HavenのCC0素材です。フォントはPretendardとGowun Batang、日本語と中国語の画面ではNoto Sans CJKを使っています（いずれもSIL Open Font License 1.1）。詳しい出典と利用条件は[素材の一覧](../ASSET_POLICY.md)（韓国語）にあります。

## 不具合・感想

止まったりおかしな動きをしたりしたら、どの場面で何が起きたかを[不具合報告](https://github.com/easygap/Missing-Floor/issues/new?template=bug_report.yml)に書いてもらえると助かります。[プレイの感想や提案](https://github.com/easygap/Missing-Floor/issues/new?template=feedback.yml)も読んでいます。

ソースからビルドする手順は[起動ガイドの「소스에서 빌드하기」](../PLAYING.md#소스에서-빌드하기)（韓国語）にあります。Unreal Engine 5.8、Visual Studioの「C++によるゲーム開発」ワークロード、Windows SDK、Git LFSが必要です。
