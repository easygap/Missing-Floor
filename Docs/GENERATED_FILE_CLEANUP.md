# 빌드·검증 임시 파일 정리

빌드와 검증 스크립트는 종료할 때 이전 실행의 임시 산출물을 정리한다. 성공·실패 모두
`finally`에서 처리하며, 정리 실패가 원래 빌드나 검증 오류를 덮어쓰지 않는다.
열린 파일을 확인하는 Windows 기능을 쓰므로, 다른 운영체제에서는 자동 삭제와 그 검사를 건너뛴다.

같은 검사와 옵션별로 최근 성공 2회, 실패 1회를 보관한다. 완료 후 24시간이 지나지 않은
결과도 남긴다. 다른 스크립트에서 화면을 살펴보거나 후속 검사를 할 시간을 확보하기 위해서다.
오래된 빌드나 검증 결과를 후속 검사의 입력 경로로 지정하면, 검사가 끝난 시점부터 다시
24시간 동안 보관한다.
오래 보관할 실행 폴더에는 빈 `.keep` 파일을 만들면 된다.

## 자동으로 정리하는 범위

- `Saved/Validation/` 아래 새로 만든 검증 폴더의 화면·영상·녹음·로그·추적 파일
- `Saved/Packages/` 아래 새 패키지의 실행 파일과 패키지 컨테이너 등 재생성 가능한 파일
- `Saved/PsoRecord/` 아래 새 실행의 임시 PSO 기록과 화면
- 다른 드라이브의 `MissingFloorBuild/`, `MissingFloorSmoke/` 바로 아래에서 새로 만든 실행 폴더
- `%LOCALAPPDATA%/IndieGame/ReviewPackages/` 바로 아래에서 새로 만든 패키지

기존 폴더를 이름이나 날짜만 보고 정리 대상으로 삼지 않는다. 이번 변경 이후 스크립트가
빈 폴더를 등록하고 완료 목록을 남긴 실행만 정리한다. 임의로 지정한 외부 경로는 이 범위에
들지 않으면 자동 정리하지 않는다. 고정 경로를 재사용하는 빌드 캐시도 유지한다.

## 보호하는 파일

소스와 원본 에셋, `Saved/Releases/`의 배포 보관본, 세이브와 그 백업은 대상에서 제외한다.
검증 폴더 안에서 만든 `.sav` 파일도 남긴다. 최근 패키지 2회와 최신 실패 결과, JSON 요약과
텍스트 기록은 보관한다. 등록 뒤 추가하거나 수정한 파일은 지우지 않는다.

스크립트를 실행하는 동안 공유 잠금을 유지하고, 모든 실행이 끝나야 정리에 필요한 독점
잠금을 잡을 수 있다. 등록 전부터 실행 중이던 프로그램도 프로세스 경로로 확인한다.
열려 있는 파일, 연결 폴더·심볼릭 링크, 범위 밖 경로는 건너뛴다. 종료되지 않은 실행은
완료 목록이 없으므로 정리하지 않는다.

삭제 직전에 경로·크기·수정 시각·SHA-256을 대조한다. 기록에 있는 파일만 개별 삭제하며
폴더를 통째로 지우지 않는다. 10초가 지나면 다음 파일부터는 다음 실행 종료 때
처리한다. 삭제한 파일의 바이트 수를 집계하므로 다른 작업의 디스크 사용량 변화가 섞이지 않는다.

## 확인 방법

`Scripts/Test-GeneratedArtifactCleanup.ps1`은 작은 임시 프로젝트에서 보관 개수, 실패 결과,
세이브·원본·최신 패키지 보호, 변경된 파일, 열린 파일, 프로세스 간 잠금, 연결 경로와
미리 보기를 검사한다. 검사에 쓴 임시 프로젝트는 종료할 때 삭제한다.

수동으로 목록을 확인할 때는 다음과 같이 실행한다. `-WhatIf`는 파일을 삭제하지 않는다.

```powershell
. ./Scripts/GeneratedArtifactCleanup.ps1
Invoke-IGArtifactCleanup -ProjectRoot (Get-Location).Path -WhatIf
```
